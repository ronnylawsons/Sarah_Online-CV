# Sarah Online CV

## Description du projet
Ce projet est un CV en ligne présentant Sarah Walker, une consultante en marketing digital. Il met en avant ses compétences, expériences professionnelles, projets et permet aux visiteurs de la contacter directement.

## Fonctionnalités principales
- **Section Accueil** : Présentation personnelle avec photo et appels à l'action
- **Section À propos** : Compétences, expériences professionnelles et projets réalisés
- **Section Blog** : Articles et conseils sur le marketing digital
- **Section Contact** : Formulaire de contact intégré
- **Navigation fluide** : Menu sticky pour un accès facile aux sections

## Technologies utilisées
- **HTML5** : Structure sémantique du site
- **CSS3** : Design responsive et moderne
- **Polices Google** : 
  - Manrope (police principale)
  - Playwrite CL (pour le logo)
  - Langar (pour les titres)

## Caractéristiques du design
- **Design responsive** : Adapté à tous les appareils
- **Palette de couleurs** : 
  - Bleu foncé (#4A4E80) pour les sections principales
  - Gris clair (#f8f8f8) pour les sections de contenu
  - Blanc (#fff) pour les éléments de carte
- **Animations** : Effets hover sur les articles de blog
- **Interface moderne** : Cards, ombres et transitions fluides

## Sections du site

### 1. Accueil (Home)
Présentation de Sarah Walker avec sa photo et deux boutons d'appel à l'action : « Mon CV » et « Contactez ».

### 2. À propos (About)
Divisée en trois sous-sections :
- **Compétences** : Liste des domaines de compétences
  - Stratégie de marketing digital
  - Gestion de campagnes publicitaires (Google Ads, Facebook Ads)
  - Optimisation SEO/SEM
  - Analyse de données
  - Gestion des réseaux sociaux
  - Création de contenu

- **Expériences professionnelles** :
  - Consultante en marketing digital - XYZ Agency (2018 - Présent)
  - Responsable des réseaux sociaux - ABC Corp (2015 - 2018)

- **Projets** :
  - Lancement d'une campagne de sensibilisation environnementale (2021)
  - Refonte du site web de XYZ Agency (2019)

### 3. Blog
Six articles sur des sujets liés au marketing digital :
- Qu'est-ce que Google Ads ?
- Astuces de gestion financière
- Top 7 des techniques de clientèle
- Apprendre le SEO en 2024
- Meilleures stratégies marketing
- Qu'est-ce qu'un consultant en marketing digital ?

Chaque article dispose d'une image, d'un titre, d'une description courte et d'un lien « Voir plus ».

### 4. Contact
Formulaire de contact simple avec les champs :
- Nom (requis)
- Email (requis)
- Message (requis)

## Comment utiliser le site
1. Clonez le dépôt : `git clone https://github.com/ronnylawsons/Sarah_Online-CV.git`
2. Ouvrez le fichier `index.html` dans un navigateur web
3. Naviguez entre les sections via le menu principal
4. Consultez les compétences et expériences de Sarah
5. Lisez les articles du blog
6. Utilisez le formulaire de contact pour envoyer un message

## Personnalisation
Pour adapter ce CV à vos besoins :
- Modifiez le contenu HTML dans `index.html`
- Personnalisez les couleurs et le design dans `style.css`
- Remplacez les images dans le dossier `img/`
- Mettez à jour les textes, compétences, expériences et projets
